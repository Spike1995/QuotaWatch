# Stage 9:Windows 桌面小组件(托盘 + 小窗 + 自启 + msix)

## 定位与边界
- 对接学习计划里已预留的 **Stage 9「开源并发布 Windows Beta」」,把它细化为「桌面小组件」方向。每张任务卡镜像 `docs/STAGE8_*.md` 的章节(目标/范围/非目标/完成条件/验证记录/学习点),落点全栈链:UI+状态 → 启动脚本 → 平台壳 → 打包。
- **保留 Web 目标**:`window_manager`/`tray_manager` 在 Web 编译会失败,用 conditional import(接口 + `_io.dart` 真实现 + `_web.dart` 空实现)隔离,Web 发布链不动。
- **凭据边界(硬规则)**:`KIMI_CODING_API_KEY`/`GLM_API_KEY` 只能由 `start_quota_watch.ps1` 注入 backend 子进程。桌面 exe **不碰 key**。因此"开机自启"注册的是**启动脚本**(在 Windows 启动文件夹放 `.cmd`,调用现有 `start_quota_watch.ps1`),而不是用 `launch_at_startup` 让裸 exe 自启 —— 这样 key 永远不进 Flutter 进程、日志、打包产物。
- **桌面 Dart http 不受 CORS 约束**,后端 `allow_origin_regex` 无需改。

## 新增依赖(pubspec.yaml)
```yaml
window_manager: ^0.4.3    # 小窗:尺寸/无边框/置顶/隐藏
tray_manager: ^0.5.0      # 托盘:图标+菜单+点击恢复
# msix 放 dev_dependencies:
msix: ^3.16.0             # 打包成可安装 .msix(S9-6)
```
> `launch_at_startup` **不用**(见上面凭据边界,自启走脚本路线)。

## 文件改动总览
1. `quota_watch/windows/` —— 由 `flutter create --platforms=windows .` 生成(native runner.exe + CMake + 图标资源),业务代码零改。
2. `quota_watch/windows/runner/resources/app_icon.ico` —— 由 `assets/logos/` 的 PNG 转换(应用图标 + 托盘图标各一份)。
3. `lib/app/desktop/desktop_controller.dart` —— 接口(`init`, `hideToTray`, `showFromTray`, `quit`)。
4. `lib/app/desktop/desktop_controller_io.dart` —— 真实现:window_manager 设 340×520 / 无边框 / 置顶 / 居中;tray_manager 装图标+菜单;`onWindowClose` 拦截关闭→隐藏到托盘。托盘"设置"项通过现成的 `AppRouter.navigatorKey` 跨树导航到 `/settings`。
5. `lib/app/desktop/desktop_controller_web.dart` —— 空实现(所有方法 no-op),保护 Web 构建。
6. `lib/main.dart` —— 改 `async main`,`WidgetsFlutterBinding.ensureInitialized()` 后调 `DesktopController.instance.init()`,用 conditional import 选择实现。
7. `lib/presentation/pages/home_page.dart` —— 仅微调:窄窗下间距/卡片密度(S9-4),单列布局已存在(700px 断点),改动极小。
8. `scripts/start_quota_watch.ps1` —— 加 `-Desktop` 开关:走 `flutter run -d windows`(或 release exe 路径),其余 backend/凭据逻辑完全复用。
9. `启动 Quota Watch 桌面版.cmd`(仓库根,新)—— 双击入口,等价 `-Desktop`。
10. `scripts/install_autostart.ps1`(新,S9-5)—— 把一个调用 `start_quota_watch.ps1 -Desktop` 的 `.cmd` 写入 `shell:startup`,可 `--uninstall`。
11. `pubspec.yaml` 的 `msix_config:` 段(S9-6)—— 配置发布者/显示名/图标,`flutter pub run msix:create` 出 `.msix`。
12. `docs/STAGE9_WINDOWS_WIDGET_TASK.md` —— Stage 9 任务卡(镜像 STAGE8 章节格式)。
13. `docs/LEARNING_LOG.md` / `docs/VIBE_CODING_LEARNING_PLAN.md` —— Stage 9 行状态由"未开始"推进,记录证据。

## 需要你注意的取舍
- **S9-5 自启不打包进 msix**:安装版的自启仍依赖 dev 仓库里的启动脚本(因为 backend+venv+key 映射在仓库侧)。把 Python backend 一并打包进安装包、做成完全自包含,是 AGENTS.md 所说的"需独立安全设计"的后续里程碑,不在本 Stage 范围。
- **托盘/应用图标需 `.ico`**:`assets/logos/` 只有 PNG,S9-1/S9-3 会生成 `.ico`(从现有 PNG 转换,沿用仅供个人学习的授权范围)。
