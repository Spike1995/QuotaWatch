# Stage 9 / 桌面数据卡片真实透明任务卡

> 日期：2026-07-24
> 状态：等待用户复验

## 目标

让桌面组件的三张数据磁贴真正透出桌面，而不是只在 Quota Watch 自己的不透明画布上混色；
同时保留文字可读性、圆角原生区域、无黑边和启动阶段的可见性。

## 当前问题

- 卡片主题已经设置半透明色，但桌面模式的 `Scaffold` 与正文渐变仍绘制不透明 `surface`。
- 因此卡片只会透出应用内部背景，看起来仍接近实色，无法与桌面自然融合。
- Windows 原生底色只会在三张磁贴区域建立后切成透明；启动、加载、错误、设置和置顶模式仍需
  保持不透明底色，避免历史上的整窗不可见。

## 非目标

- 不修改额度数据、Provider 适配器、重置时间或真实请求。
- 不截图、输出或记录真实额度内容。
- 不改变窗口层级、`Win+D`、托盘、单实例和启动器逻辑。
- 不承诺 Flutter 能模糊桌面外部像素；本轮只验收真实 alpha 混合。

## 学习点

一张半透明卡片最终能看到什么，取决于它下面的整条合成链：
桌面像素 → Windows 原生窗口底色 → Flutter 页面画布 → 卡片材质。
只降低最上层卡片的 alpha，而中间任意一层仍不透明，就不会形成真正的桌面组件透明感。
