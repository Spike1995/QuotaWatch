# 服务商 Logo 资源说明

本目录的三个 PNG 是各服务商的**官方品牌标识**，仅用于本学习项目的本地界面展示。
商标权归 OpenAI、Moonshot AI（月之暗面）、智谱 AI（Z.ai）各自所有。
本项目为个人学习用途，不分发、不商用；公开发布前请移除或另行获取授权。

| 文件 | 服务商 | 来源 | 加工 |
| --- | --- | --- | --- |
| `codex.png` | ChatGPT（OpenAI） | 官方标志 SVG（Wikimedia 收录的 OpenAI 官方资产）<https://upload.wikimedia.org/wikipedia/commons/0/04/ChatGPT_logo.svg> | 无头浏览器按 512px 渲染为 PNG |
| `kimi.png` | Kimi（Moonshot AI） | kimi.com 前端官方图标库中的 `a_Kimi` 矢量图标 | 重绘为官方应用图标样式（黑色圆角方块 + 白色标记） |
| `glm.png` | 智谱 GLM（Z.ai） | Z.ai 官网 CDN 官方 logo <https://z-cdn.chatglm.cn/z-ai/static/logo.svg> | 无头浏览器按 512px 渲染为 PNG |

重新生成方式：下载对应 SVG 后用无头 Edge/Chrome 以透明背景截图
（`--headless --default-background-color=00000000 --window-size=512,512 --screenshot=...`）。
